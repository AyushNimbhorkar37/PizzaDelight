A modern and user-friendly pizza ordering web application.  
Built with React.js (Frontend) and Node.js + Express (Backend) with MongoDB database.

---

## 🚀 Features
- Browse a variety of delicious pizzas
- Add pizzas to your cart and manage your order
- User authentication (Login/Signup)
- Admin dashboard for managing inventory and orders
- Real-time stock update after order placement
- Razorpay payment integration (test mode)

---

## 🛠 Tech Stack
- **Frontend:** React.js, Context API, Plain CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Payment Gateway:** Razorpay
